# Shield-AdBlocker Support

## Before reporting a problem

1. Open Shield from the browser toolbar.
2. Use **Pause here** if a website is broken, then reload the page.
3. Confirm which individual protection option causes the problem.
4. Record the website address, Chrome version, Shield version, and the shortest
   steps needed to reproduce it. Do not include passwords, cookie values,
   payment information, or other private data.

## What Shield currently supports

Shield reduces requests to a curated set of common advertising and tracking
domains, strips third-party cookie headers, hides recognized ad containers and
cookie banners, and performs best-effort YouTube ad cleanup. Website and
YouTube markup changes frequently, so cosmetic cleanup is not guaranteed on
every page.

Support requests should be sent through the verified support contact on the
Chrome Web Store listing.
