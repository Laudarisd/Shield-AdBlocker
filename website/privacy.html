Shield-AdBlocker Privacy Policy

Effective September 10, 2026

Shield works locally in the browser. It does not sell, share, or transmit personal information, browsing history, website content, cookie values, or usage analytics to the developer or third parties.

Local processing

Chrome evaluates packaged rules against request destinations. Packaged content scripts inspect limited page structure to hide recognized ad containers and cookie banners. A rule can remove third-party Cookie and Set-Cookie headers without Shield reading, retaining, or transmitting their values.

Protection switches and the website allowlist are stored only in chrome.storage.local. Per-tab block counts are displayed by Chrome and are not retained by Shield.

Collection, sharing, and retention

Shield has no analytics, advertising, account system, or remote server and does not collect or transmit user data. Local preferences remain until the user changes them, clears extension data, or uninstalls Shield.

Permissions

  • declarativeNetRequest: packaged blocking rules and local allowlist exceptions.
  • storage: local preferences and website allowlist.
  • All websites: packaged cosmetic filtering and third-party cookie-header protection.

Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Any information processed by Shield is used only for its user-facing content-blocking features.

Changes and contact

Material changes will be disclosed before updated data practices take effect. Questions can be sent through the verified support contact displayed on Shield's Chrome Web Store listing.
